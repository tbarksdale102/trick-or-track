# Adopt Trellis for Trick or Track

## Scope
Configure the Codex development workflow, document actual frontend/backend conventions and product invariants, preserve application behavior, and verify task/context tooling.

## Acceptance criteria
- [x] Frontend guidelines describe the vanilla JS architecture.
- [x] Backend and product rules cover traceability, credential handling and safe Jira writes.
- [x] Documentation distinguishes development tooling from product features.
- [x] Context and task lifecycle checks pass.
- [x] Application tests and HTTP checks pass.

Automatic host hook injection is optional and unverified; use manual context fallback.
